# Rozvrh

## Autor
Sarah Kameníková

## Trieda
III.BTL

## Cieľ projektu
Cieľom projektu je vytvoriť systém na automatizovanú tvorbu školského rozvrhu.
Systém eviduje ročníky, triedy, žiakov, učiteľov, predmety a učebne, zohľadňuje
obmedzenia (dostupnosť učiteľov, kapacitu a špecializáciu učební, zameranie
žiakov A/P) a generuje návrhy platného týždenného rozvrhu, ktorý si zástupca
školy môže vybrať, potvrdiť a exportovať (PDF/XLSX).

## Postup spustenia aplikácie
Aplikácia je zatiaľ vo fáze návrhu/implementácie. Postup spustenia bude
